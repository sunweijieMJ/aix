# 介绍

Aix 是一套基于 Vue 3 的企业级 UI 组件库，旨在帮助开发者快速构建高质量的 Web 应用。

## 特性

### 🎨 主题定制

基于 CSS 变量的完整主题系统，支持：
- 亮色/暗色主题
- 自定义品牌色
- 完整的 Design Token 系统

### 📦 TypeScript 支持

- 完整的类型定义
- 智能提示
- 类型推导

### ⚡ 高性能

- 基于 Vue 3 Composition API
- Tree Shaking 支持
- 按需加载

### 🔧 工程化

- Monorepo 架构
- 完整的测试覆盖
- 严格的代码规范

## 浏览器支持

基于 Vue 3，支持现代浏览器（Edge / Firefox / Chrome / Safari 最近两个版本），不支持 IE。
